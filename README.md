# Lee Way Toll

## Description
Lee Way Toll is a modern toll management application designed to simplify electronic toll collection and expense tracking. It provides users with a seamless interface to manage toll receipts, monitor expenses, and generate reports. The system integrates with digital payment gateways, ensuring secure transactions and real‑time updates. Built with scalability in mind, Lee Way Toll is suitable for both individual drivers and fleet managers. Its intuitive design reduces administrative overhead, while advanced features like receipt scanning and expense categorization enhance usability. By leveraging modern web technologies, the project ensures cross‑platform compatibility and responsive performance. The goal is to deliver a reliable, user‑friendly solution that empowers users to manage toll expenses efficiently and transparently.

## Features
- Add and manage toll expenses
- Generate digital receipts
- Expense list with filtering
- Responsive UI with modern design
- Secure payment integration

## Technologies Used
- React.js
- CSS3
- HTML5
- Node.js
