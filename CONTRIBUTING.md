# Contributing to Lee Way Toll

## Contribution Guidelines
We welcome contributions! To contribute:
- Fork the repository.
- Create a new branch for your changes.
- Follow the project's coding standards.
- Commit your changes and push to your fork.
- Open a pull request to the main branch.
- Refer to this file for detailed guidelines.

## How to Contribute
- Ensure code is clean, well‑documented, and tested.
- Submit descriptive commit messages.
- Respect existing project structure.

## Reporting Issues
- Use the GitHub Issues tab.
- Provide clear steps to reproduce.
- Include screenshots/logs if relevant.

## Suggesting Features
- Open a feature request issue.
- Explain the use case and benefits.
- Suggest possible implementation ideas.

## Code of Conduct
- Be respectful and inclusive.
- No harassment or discrimination.
- Collaborate constructively.

## Review Process
- Pull requests reviewed by maintainers.
- Automated tests must pass.
- Feedback will be provided before merging.
